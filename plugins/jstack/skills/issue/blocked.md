# Blocked

A real outcome, not a failure to hide: an unactionable brief, a decision that is not yours, missing credentials, or a fix far larger than the issue implies.

```bash
place-issue --repo <owner/repo> --issue <N> --status "Blocked"
gh issue comment <N> --repo <owner/repo> --body "Blocked: <what stopped you> / <exactly what you need to continue>"
```

Name exactly what would unblock you — "archived rows too, or only live ones?" ends the round trip that "needs clarification" wastes.

Then stay at the prompt. The answer arrives as a comment on the issue and lands in this session.
