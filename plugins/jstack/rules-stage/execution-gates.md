# Execution Gates

Hard gates — not judgment calls. Skipping one is a bug, not a style choice.

## Before you execute

Name what "done" looks like in one sentence, and which system it belongs to. If you can't name both, you're not ready to start.

## Before an API call

Read the docs first — cite what you read, not what you assume — and define "good output" specifically, before you spend money. Guessing is not research.
